
# Proyecto 3

El poyecto está enfocado en construir una página landing para un negocio. Basicamente es crear una página web simple, donde pueda exponer algún negocio.

La página web que realicé se básicamente en un emprendimiento propio que tengo con un amigo, trabajamos con pintura electroestática, Cerakote, arenado y fibra de carbono.

Siento que en vista general la página quedó aceptable, me compliqué un poco con el uso de los distintos frameworks, la correcta utilización de ellos y la ubicación y orden de la página.

sinceramente siento que es muy plana, pudo haber tenido mucho mas "flow", pero ese es el resultado. 

Lo que queda es tomar el aprendizaje y la experiencia y seguir práticando.
